Check the status of your request

Paraphrased evidence extract from eBay US Help. Source checked 2026-11-28.

Promised refund or missing return label

The buyer can check an open return or missing-item request in eBay. A buyer can ask for eBay assistance if the seller has promised a refund without issuing it or accepted a return without supplying the return label. Once issued, refunds generally return to the original payment method and are typically available within three to five business days.

Closing a request

A buyer can close a request when the issue is resolved. A closed return or case cannot be reopened, and the buyer cannot file a new one for the same transaction. A request with no activity for 21 business days is closed automatically.
